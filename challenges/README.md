# Official Teleport challenge specs

Snapshot of the challenge briefs published by Teleport at
[gravitational/careers/challenges](https://github.com/gravitational/careers/tree/master/challenges),
preserved here so this repo is self-contained for offline reading and
so AI agents working in this directory can see the exact spec without
a separate clone.

- Snapshot taken: 2026-05-13
- Source commit: `21818ba` (2026-05-05)

For the authoritative, up-to-date spec, always check
`gravitational/careers` directly — minor wording changes happen.
