The current product challenge is a design-and-present exercise around
provisioning a WireGuard network with SSO sign-on. It is more of a
"design + present" exercise than a heavy coding submission. The exact
form varies by role and year.

## What to do before submitting

1. Read the official spec / take-home prompt carefully. Note the
   evaluation criteria explicitly.
2. Apply [`../../docs/HUMANIZATION.md`](../../docs/HUMANIZATION.md)
   if you used AI assistance - the marketing-word and em-dash audits
   matter even more in product writing.
3. Apply [`../../docs/PROCESS_NOTES.md`](../../docs/PROCESS_NOTES.md)
   for recruiter / cadence expectations.

## Cross-track principles that apply

- Cut scope. A focused, specific deliverable beats a broad, generic
  one.
- Be concrete. Specific user stories, specific metrics, specific
  competitive examples beat abstract framing.
- Acknowledge tradeoffs explicitly. Reviewers want to see judgment,
  not just a list of features.
