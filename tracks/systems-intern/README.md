# Systems intern track

The systems-intern track is the internship variant of the systems
track. The exact spec is typically smaller in scope than the full
Job Worker Service challenge but uses the same review pool and the
same style of evaluation.

## Status of this directory

**Triaged, no separate corpus.** Fragment-search across the senior
brief found no candidate repos explicitly labelled "intern" with
reviewer threads.
The intern challenge is a stripped-down version of the senior brief
and candidate repositories appear under generic names that overlap
with the senior track.

Use the senior systems corpus and skip the feedback themes that are
out of scope at intern level: cgroups (and CLONE_INTO_CGROUP /
cgroup.kill), mTLS with chain verification, multi-PR stack
discipline. The lifetime, streaming, status, and authorization
themes still apply.

If you have public submission links or reviewer comment threads
specific to the intern variant, please contribute them.

## What to do before submitting

1. Read the official spec from `gravitational/careers` carefully.
   Note exactly which features are in scope for the intern variant
   versus the full challenge.
2. Read [`../systems/GUIDE.md`](../systems/GUIDE.md) and
   [`../systems/REVIEWER_PREFERENCES.md`](../systems/REVIEWER_PREFERENCES.md)
  - the review style is the same.
3. Don't pad the intern submission with features the full challenge
   asks for but the intern variant cuts. "I did more" is not the
   signal reviewers reward.
4. Apply [`../../docs/HUMANIZATION.md`](../../docs/HUMANIZATION.md)
   if you used AI assistance.

## Cross-track principles that apply

All of the systems-track guidance applies, scaled to the intern
scope. Cut, ship, defend on the followup call.
